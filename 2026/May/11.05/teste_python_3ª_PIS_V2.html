QUESTÃO 1 • Variáveis e Print

Apresentação Personalizada

Crie um programa que apresente os seus dados pessoais de forma criativa.

Personalização Obrigatória:
• Use os dados que inseriu acima (nome, idade, hobby, animal, cidade)
• Crie pelo menos 5 variáveis diferentes
• Use formatação com f-strings ou .format()
• Inclua pelo menos um cálculo (ex: ano de nascimento)
Dica: Pense em apresentar-se como se fosse um perfil de rede social
QUESTÃO 2 • Estruturas Condicionais

Classificador Personalizado

Crie um programa que classifique algo relacionado com o seu hobby.

Personalização Obrigatória:
• O programa deve estar relacionado com o HOBBY que indicou
• Use estruturas if/elif/else
• Peça input ao utilizador
• Dê mensagens personalizadas com o seu nome
Exemplo: Se o hobby é futebol, classifique equipas ou jogadores
Se é fotografia, classifique tipos de câmaras ou técnicas
QUESTÃO 3 • Listas e Ciclos

Lista de Favoritos

Crie um programa que trabalhe com listas relacionadas com os seus interesses.

Personalização Obrigatória:
• Crie uma lista com pelo menos 5 itens relacionados com o seu HOBBY ou ANIMAL FAVORITO
• Use um ciclo for ou while para percorrer a lista
• Inclua o nome da sua CIDADE em pelo menos uma mensagem
• Use métodos de lista (append, remove, sort, etc.)
Pode ser uma lista de: locais na sua cidade, raças do seu animal favorito,
equipamento do seu hobby, etc.
QUESTÃO 4 • Funções

Função Personalizada

Crie uma função útil relacionada com a sua vida ou interesses.

Personalização Obrigatória:
• A função deve ter um nome relacionado com o seu HOBBY ou ANIMAL
• Receber pelo menos 2 parâmetros
• Fazer um cálculo ou processamento relevante
• Incluir comentários explicativos com exemplos pessoais
Exemplos: calcular_tempo_treino(), comparar_precos_equipamento(),
calcular_idade_animal_em_anos_humanos()
QUESTÃO 5 • Dicionários

Base de Dados Pessoal

Crie um programa que use dicionários para organizar informação pessoal.

Personalização Obrigatória:
• Crie um dicionário com os seus dados (nome, idade, cidade, hobby, animal)
• Adicione pelo menos 2 campos extra personalizados
• Use métodos de dicionário (keys(), values(), items(), get())
• Apresente os dados de forma formatada
Pense em criar um perfil completo seu, ou de alguém que admira

💡 Dicas para Máxima Pontuação:

✓ Use os seus dados reais em TODAS as questões

✓ Teste o código antes de submeter
✓ Seja criativo nas mensagens apresentadas
✓ Evite código genérico tipo "exemplo1", "teste", "valor"
